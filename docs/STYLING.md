# Keepio — 스타일 가이드

> 모든 UI는 이 토큰과 원칙을 따른다. 톤은 **토스처럼 미니멀한 그레이스케일**.

## 디자인 원칙

1. **그레이스케일 우선** — 화면의 기본 색은 흑·백·회색.
2. **AI는 보라색 한 톤** — AI가 한 일(자동 분류·추천·요약·비교 도우미·자연어 검색)에만 `#7F77DD`를 쓴다. 그 외에는 쓰지 않는다.
3. **배제 목록** — 그라데이션 ❌, 과한 그림자 ❌, 이모지 ❌.
4. **모바일 우선** — 기준 뷰포트 iPhone 13/14 = **375 × 812**.
5. **정보 출처 구분** — AI 자동 추출 정보는 **검은 텍스트**, 사용자 직접 입력 필드는 **옅은 회색 dashed** 테두리로 시각 구분한다.

## 색상 토큰

| 토큰 | 값 | 용도 |
|---|---|---|
| AI Accent | `#7F77DD` | AI 기능 강조 (오직 이 용도) |
| Foreground | 검정 계열 | 기본 텍스트 / AI 추출 정보 |
| Muted | 회색 계열 | 보조 텍스트 / placeholder |
| User-input border | 옅은 회색 dashed | 사용자 직접 입력 필드 |
| Background | 흰색 / 아주 옅은 회색 | 화면 바탕 |

> 구체 hex 스케일은 Tailwind v4 테마(`@theme`)에 정의하고, 여기 토큰 이름으로 참조한다. 임의 색을 인라인으로 박지 않는다.

## 컴포넌트 규칙

- **버튼** — 주요 액션은 검은 배경/흰 텍스트, 보조는 회색. 둥근 모서리, 그림자 없음.
- **카드** — 얇은 회색 보더 또는 아주 옅은 배경. 그림자 최소.
- **컬렉션 표시** — 자식이 있으면 **카드 그리드**, 말단이면 **리스트**.
- **아이템 카드** — 카테고리 타입별로 필드가 다르다. 출처·메모는 공통.
- **하단 탭바**로 주요 화면 이동.

## Tailwind 사용

- 유틸리티 클래스를 직접 쓴다. 디자인 토큰은 `@theme`에 정의해 재사용한다.
- 반복되는 패턴은 컴포넌트로 추출한다 (클래스 복붙 금지).
- 색은 위 토큰만 사용 — 임의 hex 금지.
