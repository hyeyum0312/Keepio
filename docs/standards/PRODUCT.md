# Product / Planning Rules

- User outcome: external share → save → classify → bucket → publish; each feature must name the user problem and acceptance criteria.
- Confirmed: bookmark↔category N:M; normalized URL reused per user; public publication URL; immutable publication snapshots; hybrid mobile shell.
- Distinguish **decision** vs **proposal** vs **open question**. Never silently decide billing limits, delete retention, AI auto-apply thresholds, or restore-on-resave policy.
- For each change specify states: empty/loading/success/error/partial failure, permission, duplicate, offline/retry, delete/recover, analytics if actually instrumented.
- Write acceptance criteria as observable outcomes (Given/When/Then); include non-goals and dependency changes.
- Keep MVP scope: no user template builder, collaborative editing, payments, social feed.
