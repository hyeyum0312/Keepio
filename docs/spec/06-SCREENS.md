# keepio — 화면 목록 (Screen Index)

모든 화면에 고유 ID를 붙이고, 기능(FEAT)·기획서·Figma·경로를 이 표 하나에서 연결한다. 화면이 추가되거나 상태가 바뀌면 이 표를 함께 고친다.

## ID 규칙

- 형식: `영역-번호` (예: `AUTH-01`). 번호는 영역 안에서 두 자리 일련번호이며 재사용하지 않는다(폐기한 화면 번호는 비워 둔다).
- 팝업·모달: 부모 화면 ID 뒤에 `-M번호` (예: `PUB-03-M1`).
- 빈·로딩·오류·성공 상태는 별도 ID를 두지 않고 화면 기획서에서 다룬다.
- 웹과 앱이 같은 화면이면 같은 ID를 쓰고 플랫폼 열에 함께 적는다.
- Figma 페이지·프레임 이름, 화면 기획서 제목, 이슈 제목은 화면 ID로 시작한다(예: `AUTH-01 로그인`).
- 기능(FEAT)은 동작·데이터 계약, 화면 ID는 사용자가 보는 페이지다. 한 화면에 여러 FEAT, 한 FEAT에 여러 화면이 걸릴 수 있다.

| 영역     | 뜻                          |
| -------- | --------------------------- |
| `HOME`   | 랜딩                        |
| `INFO`   | 약관·정책 등 안내 페이지    |
| `AUTH`   | 로그인·가입·계정 복구       |
| `LINK`   | 내 링크·링크 상세·일괄 정리 |
| `CAT`    | 카테고리·태그 관리          |
| `BKT`    | 버킷                        |
| `TPL`    | 템플릿                      |
| `PUB`    | 발행물 목록·편집            |
| `PUBLIC` | 비로그인 공개 페이지        |
| `SET`    | 설정                        |
| `APP`    | 앱 전용(스플래시·공유 확장) |

## 상태 값

`미착수` → `기획`(화면 기획서 있음) → `디자인`(Figma 완료) → `개발` → `완료`. 기능만 동작하는 최소 화면(D-09 전)은 `최소 UI`로 표시한다.
