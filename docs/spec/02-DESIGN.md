# keepio — UX/UI 디자인 명세 v0.3

## 디자인 원칙

콘텐츠 중심의 미니멀 디자인. 사용자의 핵심 작업은 **저장 → 정리 → 버킷 → 발행**. AI는 별도 챗봇보다 맥락형 추천·적용 인터랙션으로 제공.

## 정보 구조

- 로그인 전: 랜딩(제품 설명, 기능, 공개 페이지 예시, 시작하기), 로그인/온보딩
- 로그인 후: **내 링크**(전체/미분류/분류 완료), **버킷**, **발행**, **템플릿**
- 보조: 링크 상세, 카테고리/태그 관리, 검색, 설정, 사용량
- 미분류/분류 완료는 별도 최상위 메뉴가 아니라 내 링크의 탭으로 구성

## 필수 화면

| 화면           | 필수 UI/동작                                                     |
| -------------- | ---------------------------------------------------------------- |
| 랜딩           | 제품 가치, 실제 발행물 예시, CTA                                 |
| 내 링크        | 목록, 검색, 필터, 다중 선택, 상태 탭                             |
| 링크 상세      | 썸네일, 원본 URL, 복수 카테고리, 태그, 버킷 추가                 |
| 일괄 정리      | AI 추천 결과 확인, 다중 카테고리 적용, 실패 피드백               |
| 카테고리 관리  | 생성, 수정, 유사 이름 안내, 병합 확인, 삭제                      |
| 버킷 목록/상세 | 생성, 링크 추가·제거, 순서 변경, 발행 시작                       |
| 발행물 목록    | 초안/발행/발행 취소, 공유, 편집, 삭제                            |

| 공개 페이지    | 비로그인 열람, 모바일/데스크톱 반응형                            |
| 설정           | 계정, 사용량, 데이터 관리                                        |

## 핵심 UX 흐름

1. 외부 앱 공유 → 즉시 저장 완료 안내 → 비동기 AI 분류 진행 표시.
2. 내 링크에서 미분류 확인 → AI 추천 복수 카테고리 확인/수정 → 일괄 적용.
3. 링크를 여러 버킷에 추가 → 버킷별 순서 지정.
4. 버킷 전체 또는 카테고리별/개별 링크 선택 → 템플릿 → 편집 → 미리보기 → 발행.
5. 발행 후 수정은 초안에 반영 → 명시적 수정 발행 시 공개 버전 교체.

## 템플릿

- 기본형: 제목, 소개, 카드 리스트, 섹션으로 구성된 범용형.
- 매거진형: 큰 커버, 강조 타이포, 이미지/글 섹션을 활용하는 편집형.
- 공통 블록: Heading, Text, Image, LinkCard, Divider, Section.
- 이미지 업로드/교체, 텍스트 수정, 블록 추가·삭제·재정렬.
- MVP에서 자유형 캔버스/사용자 템플릿 제작 기능은 제외.

## 디자인 산출물

모바일 우선 와이어프레임, 반응형 웹, 컴포넌트, 색상·타이포·간격·반경 토큰, 주요 사용자 흐름, 빈/로딩/오류/성공 상태, 템플릿 두 종류, 개발용 화면별 동작 명세.

## UX 주의점

- 카테고리는 다중 선택이므로 체크박스/칩 UI 사용.
- AI 추천과 실제 적용 상태를 명확히 구분.
- 삭제는 원본 북마크/버킷/발행물 중 무엇을 삭제하는지 구체적으로 표시.
- 발행은 공개 범위 경고 및 발행 취소 동작 제공.
- 모바일 하단 내비게이션은 핵심 메뉴만 배치.
