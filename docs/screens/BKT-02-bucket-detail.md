# BKT-02 버킷 상세

- 경로: `/buckets/[id]` (제안) · 플랫폼: 웹·앱
- 관련: ADR-018(링크 원본 하나·버킷은 참조·발행은 라이브) / ADR-014(버킷은 워크스페이스 소유, MCP) / LINK-01(같은 링크 줄·선택 막대) / OPEN-QUESTIONS D-18
- 시안: [BKT-02 PC](https://claude.ai/artifact/TVK97VZWLdiXH6GdM6PiBx#artboard-BKT02-pc), [AI에서 활용 모달](https://claude.ai/artifact/TVK97VZWLdiXH6GdM6PiBx#artboard-MCP-modal-pc)
- 마지막 확인: 2026-11-21 (코드 없음, 시안만)

## 목적

주제별로 모은 링크를 보고, 순서를 정하고, 공유 페이지로 내보내거나 AI(MCP)에 연결하는 곳.

## 진입·나가기

- [예정] 홈 버킷 카드, 사이드바 "버킷" → 버킷 목록(BKT-01) → 버킷 상세.
- [예정] [공유 페이지 만들기] → 발행 편집기(PUB-02).

## 구성 (위 → 아래)

1. [예정] 버킷 머리: 썸네일(132×96, 반경 18) · 이름(18px) · "링크 N개 · N일 전 업데이트" · 설명 한 줄(없으면 숨김) · ⋯ 메뉴.
2. [예정] 버튼 줄: [+ 링크 추가] [공유 페이지 만들기] [AI에서 활용 · 꺼짐].
3. [예정] 링크 추가 패널(접힘이 기본): "저장한 링크에서 고르기".
4. [예정] 목록 머리: 모두 선택 + "링크" + 개수 | 이 버킷에서 검색 · 정렬 · 목록형/카드형.
5. [예정] 링크 목록, [더 보기].
6. [예정] 선택 작업 막대.

## 요소별 규칙

### 버킷 머리

- [예정] 썸네일은 사용자가 고른 그림, 없으면 버킷 ID로 정한 중성 톤 아트 8장 중 하나.
- [예정] ⋯ 메뉴: 이름·설명·썸네일 수정 / 버킷 삭제.

### + 링크 추가 (ADR-018 4번)

- [예정] **새 주소를 저장하는 칸은 두지 않는다.** 새 링크는 내 링크(LINK-01)에서 저장한다.
- [예정] 누르면 "저장한 링크에서 고르기" 패널이 열린다. 회색 배경 없이 위아래 구분선으로 섹션을 나눈다.
- [예정] 고를 범위 탭: 최근 저장 · 미분류 · 전체. 제목·주소·태그로 검색.
- [예정] 줄마다 체크박스 + 작은 썸네일(72×44) + 제목(14px) + 주소(13px). 이미 이 버킷에 있는 링크는 체크된 채 비활성, 주소 줄에 "이미 들어 있음".
- [예정] [닫기] [N개 넣기]. 넣으면 버킷–링크 연결만 만든다(링크 복사 아님).

### 공유 페이지 만들기 / AI에서 활용

- [예정] [공유 페이지 만들기] → 발행(PUB). 발행은 라이브: 원본을 고치면 공개 페이지도 바뀐다(ADR-018 5번, 스냅샷 여부는 D-18).
- [예정] [AI에서 활용]은 버킷별 "AI 연결 허용"(MCP) 설정, 기본값 꺼짐. 버튼에 현재 상태(· 꺼짐)를 적는다. 설계는 BKT-02-M1 모달 보드.

### 링크 목록 (LINK-01과 같게)

- [예정] 줄·카드 모양, 썸네일 안 체크박스, 목록형/카드형 전환, 제목 14px·주소 12px, [더 보기] 모두 내 링크와 같다. 컴포넌트를 함께 쓴다.
- [예정] ⋯ 메뉴: 수정 → 이미지 바꾸기 → 다른 버킷으로 → (구분선) → **버킷에서 빼기**. 링크 삭제는 넣지 않는다(내 링크에서만, ADR-018 3번).
- [예정] 링크 수정은 원본을 바꾼다. 수정 폼 아래에 "내 링크와 다른 버킷, 공유 페이지에도 함께 바뀌어요"를 보여 준다(ADR-018 6번).
- [예정] 정렬: 최근 추가순 · 오래된순 · 제목순 · 직접 순서. **"직접 순서"를 골랐을 때만** 메뉴에 "순서 편집"이 생기고, 그때 줄 앞에 ⋮⋮ 끌기 손잡이가 보인다.
- [예정] 버킷 안 순서는 버킷–링크 연결 행에 저장한다(ADR-018 2번).
- [예정] 이 버킷에서 검색(버킷 안 카테고리 칩은 두지 않는다 — 검색으로 충분, 2026-11-21).

### 선택 작업 막대

- [예정] "N개 선택 · 다른 버킷으로 · 카테고리 변경 · 버킷에서 빼기 · ✕". 링크 삭제는 없다.
- [예정] 고를 링크가 0개면 모두 선택 체크박스를 그리지 않는다.

## 상태

- [예정] 링크 0개: 빈 안내와 [+ 링크 추가]만. 모두 선택·검색·정렬은 숨김.
- [예정] 설명이 없으면 머리의 설명 줄을 그리지 않는다.
