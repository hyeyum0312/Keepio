# LINK-03 링크 상세·수정 (모달)

- 경로: 내 링크·홈 위에 뜨는 모달. 주소는 `?edit=<링크 id>` · 플랫폼: 웹·앱
- 관련: FEAT-011(제목 수정·선택) / FEAT-010(제목·썸네일·이미지 바꾸기) / FEAT-008(카테고리) / FEAT-002(삭제) / ADR-015 / BKT(버킷, 예정)
- 시안: [LINK-03 링크 상세·수정 모달](https://claude.ai/artifact/TVK97VZWLdiXH6GdM6PiBx#artboard-LinkEdit-modal)
- 마지막 확인: 2026-11-22 (시안만. 지금 코드는 줄 안에서 고치는 인라인 수정)

## 목적

링크 하나의 제목·카테고리·버킷·태그를 한곳에서 고친다. 줄 안에서 고치면 칸이 좁아 카테고리·버킷까지 담을 수 없다(2026-11-22 사용자 결정).

**별도 상세 화면(`/links/[id]`)은 만들지 않는다.** 이 모달이 상세를 겸한다.

## 진입·나가기

- [예정] 내 링크(LINK-01)·홈(HOME-02)의 줄 끝 ⋯ 메뉴 → "수정". 주소에 `?edit=<링크 id>`가 붙는다.
- [예정] 주소로 바로 열 수 있다(새로 고침·뒤로 가기·링크 전달). 없는·남의 링크 id면 모달을 열지 않고 목록만 보여 준다.
- [예정] 바깥 누름 · Esc · [취소] · [닫기]로 닫고 주소에서 `?edit`을 뺀다. **저장 중에는 닫지 않는다.**
- [예정] 열면 포커스가 제목 칸으로, 닫으면 눌렀던 ⋯ 버튼으로 돌아간다. 모달 안에서 Tab이 돌게 가둔다(`aria-modal="true"`).

## 구성 (위 → 아래)

1. [예정] 머리: "링크 수정" + [닫기].
2. [예정] 썸네일(160×96) · 주소 · [이미지 바꾸기] [원본 열기].
3. [예정] 제목(1~100자, 비우면 페이지 제목 → 사이트 이름).
4. [예정] 카테고리: 고르기 부품(FEAT-008 AC-13) 하나. "링크당 하나" 안내.
5. [예정] 버킷: 들어 있는 버킷 칩(각각 ✕로 빼기) + [+ 버킷에 추가]. 버킷 기능 전까지 준비 중.
6. [예정] 태그: 칩 + 입력칸(Enter·쉼표로 추가, 최대 10개·개당 30자).
7. [예정] 바닥: [삭제] … [취소] [저장].

## 요소별 규칙

- [예정] **저장은 바뀐 항목만 보낸다.** 제목·카테고리는 `PATCH /api/bookmarks/:id`, 태그는 `PUT /api/bookmarks/:id/tags`, 버킷은 버킷 API. 아무것도 바뀌지 않았으면 요청 없이 닫는다.
- [예정] 삭제는 휴지통으로 보낸다(확인 창 없음, FEAT-002). 모달을 닫고 목록에서 그 줄이 사라진다.
- [예정] 카테고리·태그는 모달을 닫지 않고 바로 고친다. 새 카테고리는 고르기 부품 안에서 만든다.
- [예정] 이미지 바꾸기는 FEAT-010의 업로드를 그대로 쓴다.

## 상태

- [예정] 저장 중: [저장]이 "저장 중…"으로 바뀌고 닫기·바깥 누름을 막는다.
- [예정] 오류: 모달을 열어 둔 채 해당 칸 아래에 서버 문구를 보여 준다(ADR-009). 제목 100자 초과면 오류 테두리와 [저장] 비활성.
- [예정] 모바일: 아래에서 올라오는 전체 시트. 버킷 줄은 접고 제목·카테고리·태그만 먼저 보여 준다.
- [예정] 휴지통(LINK-02)의 링크는 모달을 열지 않는다([복구]만 있다).

## 차이 (코드 ↔ 시안)

- [차이] 지금 코드는 줄 안에서 제목만 고치는 인라인 수정이다(FEAT-011 AC-01, 구현됨). 모달로 바꾸면 그 부분과 테스트를 걷어낸다.
