# LINK-04 AI로 한 번에 정리

- 경로: 홈(HOME-02)·내 링크(LINK-01)에서 열리는 패널(별도 주소 미정) · 플랫폼: 웹·앱
- 관련: OPEN-QUESTIONS D-17(방향 합의, 출시 후 1순위) / D-03(저장 시 제안, 별개) / D-02(미분류 정의) / FEAT-008(카테고리) / ADR-014(AI 요약)
- 시안: [상태·예외 보드 8번](https://claude.ai/artifact/TVK97VZWLdiXH6GdM6PiBx#artboard-Home-sample-states)
- 마지막 확인: 2026-11-21 (코드 없음, 시안만)

## 목적

미분류로 쌓인 링크를 한 번에 정리한다. AI가 카테고리를 제안하고, 사용자는 훑어본 뒤 한 번에 적용한다.

## 범위 (D-17)

- [예정] **AI는 카테고리만 제안한다.** 태그는 건드리지 않는다(사람마다 기준이 달라 난립하기 쉽고, 사용자 자신의 말로 남겨 둔다).
- [예정] 제안만 하고 바꾸지 않는다. [적용] 전에는 아무것도 바뀌지 않는다.
- [예정] 버킷 추천은 나중에 임베딩 유사도로(생성형 호출 없이) 검토.
- [예정] 태그 추천을 넣는다면 새 태그를 만들지 않고 **이미 있는 태그 중에서만** 고른다.

## 진입·나가기

- [예정] 홈 "최근 추가한 링크" 섹션 머리의 [AI로 한 번에 정리 · 미분류 N]. **미분류가 2개 이상일 때만** 보인다.
- [예정] 하루 횟수 한도에 닿으면 버튼이 "오늘은 다 썼어요 · 내일 다시 쓸 수 있어요"(누를 수 없음)로 바뀐다. 하나씩 정리는 그대로 쓸 수 있다.
- [예정] [취소]·[적용] 뒤 원래 화면으로.

## 구성 (단계)

1. [예정] 정리하는 중: "미분류 N개를 살펴보는 중이에요" + "보통 10초 안에 끝나요". 화면을 떠나도 계속된다.
2. [예정] 제안 목록: "AI 제안 N개" + "맞는지 훑어보고 적용하세요. 적용 전에는 바뀌지 않아요."
3. [예정] 적용 뒤: "N개를 정리했어요" 토스트 + [되돌리기].

## 요소별 규칙

### 제안 목록

- [예정] 줄마다: 썸네일 · 제목(14px) · 주소(12px) · **출처 표시** · 카테고리 선택 · ✕(이 링크 빼기).
- [예정] 출처 표시 세 가지
  - `AI 제안` — AI가 고른 카테고리.
  - `전에 넣은 곳` — AI가 내용을 못 읽은 링크. 같은 사이트를 전에 넣은 카테고리를 **규칙으로** 추천(비용 0). 주소 줄에 "내용을 읽지 못했어요".
  - `직접 골라 주세요` — 못 읽었고 기록도 없음. 빨강 글자, 카테고리 칸은 "카테고리 선택". 안 고르면 미분류로 남는다.
- [예정] 목록 아래 "… N개 더 · 안 고른 줄(직접 골라 주세요)은 미분류로 남아요".
- [예정] [취소] [N개 적용] — 고른 줄 수만 센다.
- [예정] 적용 후 [되돌리기]는 이번에 적용한 것을 **한 번에 전부** 되돌린다.

### 비용 관리 (D-17)

- [예정] 저장할 때 만든 **요약·제목·도메인 텍스트만** 보낸다. 원본을 다시 읽지 않고, 이미지도 보내지 않는다(ADR-014 6번의 요약 재사용).
- [예정] 요청 한 번에 최대 50개를 묶고, 싼 모델에 정해진 형식(JSON)으로만 받는다.
- [예정] 사용자가 누를 때만 실행한다(백그라운드 없음). 하루 횟수 한도를 둔다.
- [예정] 요약·제목이 없는 링크(쿠팡 등 봇 차단, D-16)는 **AI에 보내지 않는다**.
- [예정] 중복·같은 주소 다른 표기는 AI 없이 URL 정규화로 걸러낸다(FEAT-001 규칙).

## 상태

- [예정] 미분류 0~1개: 버튼을 그리지 않는다.
- [예정] 한도 초과: 버튼 비활성 + 문구.
- [예정] 실패: 아무것도 바뀌지 않았음을 알리고 다시 시도하게 한다. 하나씩 정리는 계속 가능.
