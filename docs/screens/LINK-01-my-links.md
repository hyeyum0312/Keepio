# LINK-01 내 링크

- 경로: `/links` (이전 이름 "전체 링크") · 플랫폼: 웹·앱
- 관련: FEAT-001(저장) / FEAT-002(목록·삭제·복구) / FEAT-010(제목·썸네일) / FEAT-011(제목 수정·여러 개 선택) / FEAT-008(카테고리, 예정) / ADR-018
- 시안: [PC 목록형](https://claude.ai/artifact/TVK97VZWLdiXH6GdM6PiBx#artboard-LinksAll-pc), [PC 카드형](https://claude.ai/artifact/TVK97VZWLdiXH6GdM6PiBx#artboard-LinksAll-grid-pc), [모바일](https://claude.ai/artifact/TVK97VZWLdiXH6GdM6PiBx#artboard-LinksAll-m)
- 마지막 확인: 2026-11-21 (work 브랜치, `features/bookmarks`)

## 목적

저장한 링크를 모두 보고, 저장·수정·정리(카테고리·버킷)·삭제를 하는 곳. 링크의 **원본이 사는 화면**이다(ADR-018).

## 진입·나가기

- [구현] 사이드바 "내 링크", 모바일 하단 탭 "링크", 홈 "최근 추가한 링크 → 전체 보기".
- [구현] 제목 링크를 누르면 원본 주소를 새 탭으로 연다.
- [구현] 삭제한 링크는 휴지통(`/trash`, LINK-02)에서 복구.

## 구성 (위 → 아래)

1. [구현] 페이지 제목 "내 링크"(18px).
2. [구현] 저장 카드(홈과 같은 폼).
3. [예정] 카테고리 칩 줄(전체·미분류·…·[+ 카테고리]).
4. [구현] 목록 머리: 모두 선택 체크박스 + 제목 + 개수 배지 | 모바일 [선택] · 목록형/카드형 전환.
5. [구현] 링크 목록, 맨 아래 [더 보기].
6. [구현] 선택 작업 막대(하나라도 고르면 화면 아래에 붙음).

## 요소별 규칙

### 저장 카드 (FEAT-001)

- [구현] 홈과 같은 컴포넌트(`SaveLinkCard`). 링크 칸 + [저장], 제목·태그는 "추가 정보 입력하기(선택)"로 펼침.
- [구현] 같은 주소를 다시 저장하면 새로 만들지 않고 기존 링크를 쓴다. 휴지통에만 있으면 그 행을 지우고 새로 저장(ADR-017).

### 카테고리 칩 (FEAT-008)

- [예정] 목록 위에 칩 줄: 전체 · 미분류 · 카테고리들 · [+ 카테고리]. 고른 칩 이름이 아래 목록 제목이 된다. "미분류"는 카테고리 없는 링크(D-02). **미분류만 모아보기**가 여기서 나오고, 나중에 이 화면에 [AI로 한 번에 정리](LINK-04)를 붙인다(2026-11-22 사용자 요청).
- [예정] 선택 막대의 "카테고리 변경": 고른 링크 여러 개에 카테고리를 한 번에 적용한다. 그 자리에서 새 카테고리도 만든다. 홈과 같은 고르기 부품(FEAT-008 AC-13)을 쓴다. 시안은 아직 없다(UI부터 맞춘 뒤 구현).
- [예정] 칩 줄의 관리 메뉴에서 이름 바꾸기·합치기·삭제·순서(카테고리 관리 화면 CAT-01 대신 여기서).

### 목록 머리

- [구현] 제목 16px + 개수 배지. 지금 제목은 "정리한 링크"(칩이 없어서).
- [차이] 시안의 제목은 고른 칩 이름("전체")이다. FEAT-008에서 칩과 함께 "전체"로 바꾼다.
- [구현] 모두 선택 체크박스: 불러온 링크를 모두 고르거나 푼다(일부면 중간 상태). PC는 늘, 모바일은 선택 모드에서만. **고를 링크가 0개면 그리지 않는다**(비활성 아님, 2026-11-21).
- [구현] 모바일 [선택] 버튼도 링크 0개면 그리지 않는다. 선택 모드 중에는 [완료].
- [구현] 목록형/카드형 전환은 화면 상태(새로고침하면 목록형). 고른 링크는 전환해도 유지.

### 링크 줄·카드 (FEAT-002·010·011)

- [구현] 목록형: 한 판 안에서 줄을 나눔. 썸네일 PC 160×96·모바일 120×72. 카드형: 썸네일 16:10이 위에 오는 2·3열 격자.
- [구현] 내용: 썸네일 · 제목(14px, 굵게, 한 줄 줄임) · 주소(12px) · 태그 칩. 제목이 사이트 이름으로 보이는 링크는 끝에 "제목 넣기".
- [예정] 분류 줄(2026-11-22 사용자 요청): 주소 아래 한 줄에 **카테고리 → 버킷 → 태그** 순으로 모은다. 모양으로 종류를 구분한다 — 카테고리는 폴더 아이콘 + 회색 알약(링크당 하나), 버킷은 버킷 아이콘 + 테두리 알약(여러 개), 태그는 `#태그`.
  - 미분류이고 버킷도 없으면 **분류 줄을 그리지 않는다**(빈 줄을 만들지 않는다).
  - 버킷은 PC 목록형 2개, 카드형·모바일 1개까지 보이고 나머지는 `+N`.
  - 카테고리 이름은 링크 응답의 `category.name`을 쓴다(FEAT-008 데이터 계약). 버킷 이름은 버킷 기능과 함께 붙인다.
- [구현] 썸네일 왼쪽 위 체크박스(흰 바탕·그림자, 고르면 잉크 + 흰 체크, 누르는 영역 44px). PC는 마우스 올린 썸네일과, 하나라도 고르면 모든 썸네일에 보인다.
- [구현] 줄 끝 ⋯ 메뉴: 수정 → 이미지 바꾸기 → (구분선) → 삭제. 바깥 누름·Esc로 닫고, Esc면 버튼으로 포커스 복귀.
- [예정] "수정"은 줄 안에서 고치지 않고 **모달**을 연다(2026-11-22 결정). 모달이 제목·카테고리·버킷·태그를 한곳에서 다룬다: [LINK-03](LINK-03-link-edit-modal.md).
- [구현] 수정: 제목 자리가 입력칸으로 바뀜(Enter·[저장] 저장, Esc·[취소] 닫기). 1~100자, 비우면 페이지 제목 → 사이트 이름으로 돌아감.
- [예정] 태그 편집(TagInput + `PUT tags`): 시안은 끝났고 코드는 아직. 모달 안에서 칩 추가·삭제, Enter·쉼표로 추가, 최대 10개·개당 30자.

### 선택 작업 막대 (FEAT-011)

- [구현] "N개 선택 · 버킷에 추가 · 공유 페이지 만들기 · 카테고리 변경 · 삭제 · ✕". 화면 아래에 붙는다. ✕·Esc로 선택 해제.
- [구현] 준비 중: 버킷에 추가 · 공유 페이지 만들기 · 카테고리 변경.
- [구현] 여러 개 삭제: 확인 창 없이 휴지통으로(동시 4개). "N개를 휴지통으로 옮겼어요". 일부 실패하면 실패한 것만 고른 상태로 남고 "N개는 옮기지 못했어요. 다시 시도해 주세요."
- [예정] "버킷에 추가"는 ADR-018에 따라 링크를 복사하지 않고 버킷과 연결만 만든다.

## 상태

- [구현] 빈 목록: "저장한 링크가 없어요." 모두 선택·선택 버튼 없음.
- [구현] 더 불러오기: 서버 커서 기반 [더 보기].
- [구현] 휴지통(LINK-02)에는 체크박스·수정·이미지 바꾸기가 없고 [복구]만 있다.
- [구현] 다시 불러온 목록에 없는 링크는 선택에서 빠진다.
- [구현] 디자인 미리보기 `/preview/links`(샘플 데이터, 배포에서 404).

## 차이 (코드 ↔ 시안)

- [차이] 목록 제목: 코드 "정리한 링크" ↔ 시안 "전체"(칩에서 고른 이름). FEAT-008에서 맞춘다.
- [차이] 모바일 + 버튼(떠 있는 저장 버튼): 시안에 있고 코드에 없다. 넣을지 정할 것.
- [차이] 검색·정렬: 시안에 있으나 서버 기능 전까지 넣지 않음.
