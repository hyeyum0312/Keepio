- 경로: `/` (비로그인은 HOME-01 랜딩) · 플랫폼: 웹·앱
- 관련: FEAT-009(앱 틀·홈) / FEAT-001·002(저장·목록) / LINK-04(AI 정리, 예정) / OPEN-QUESTIONS D-02·D-17
- 시안: [홈 1-B 샘플](https://claude.ai/artifact/TVK97VZWLdiXH6GdM6PiBx#artboard-Home-sample-pc), [상태·예외](https://claude.ai/artifact/TVK97VZWLdiXH6GdM6PiBx#artboard-Home-sample-states)

## 목적

로그인 후 첫 화면. 서비스 구조(저장 → 정리 → 버킷 → 공유)를 보여 주고, 최근 저장한 링크를 한 장씩 정리하게 한다.

## 진입·나가기

- [구현] 로그인하면 `/`. 비로그인은 랜딩(FEAT-006).
- [구현] 사이드바 "링크 추가"(`/?save=1`)로 들어오면 저장 칸이 열린 채 시작(모바일은 시트).
- [구현] "최근 추가한 링크"의 "전체 보기" → 내 링크(`/links`).

## 구성 (위 → 아래)

1. [구현] 앱 틀: PC 사이드바(홈·내 링크·버킷·공유한 페이지·MCP 연결 | 링크 추가), 위쪽 막대(검색·알림·계정). 모바일은 하단 탭(홈·링크·버킷·공유)과 머리. 사이드바 접기 상태는 새로고침 뒤에도 남는다.
2. [구현] 저장 카드(PC는 늘 맨 위, 모바일은 + 버튼 시트).
3. [구현] 최근 추가한 링크.
4. [구현] 준비 중 버킷 · 공유용 링크(데이터 없으면 숨김, 지금은 서버 없어 항상 숨김).

## 요소별 규칙

### 사이드바·탭 (FEAT-009)

- [구현] 메뉴: 홈 · 내 링크 · 버킷(준비 중) · 공유한 페이지(준비 중) · MCP 연결(준비 중) | 링크 추가. "카테고리" 메뉴는 없앴다(내 링크의 카테고리 칩이 대신, FEAT-008).
- [구현] 1024px 미만은 아이콘만. 휴지통·설정·화면 모드·로그아웃은 계정 메뉴.

### 저장 카드 (FEAT-001)

- [구현] 링크 칸 + [저장]. 제목·태그는 "추가 정보 입력하기(선택)"로 펼침(기본 접힘, 접어도 값 유지). 안내 "링크를 붙여넣으면 제목·썸네일을 자동으로 가져와요."
- [구현] 모바일은 본문 칸 없이 오른쪽 아래 + 버튼 → 아래에서 올라오는 시트.

### 최근 추가한 링크 (FEAT-009, 이전 이름 "정리할 링크")

- [구현] 섹션 제목 16px, 줄 끝에 "전체 보기". 최근에 저장한 활성 링크를 한 장씩. 건너뛰면 다음, 이번 방문에 다시 안 나옴. 남은 링크가 0개면 섹션이 사라진다.
- [구현] **미분류를 먼저 보여 준다**(2026-11-22). 같은 묶음 안에서는 최근 저장 순. 미분류를 다 정리하면 카테고리가 있는 링크가 나온다.
- [구현] 미분류만 걸러내지 않는다(D-19, 2026-11-22). 카테고리를 정한 링크도 남고, 고르기에 그 카테고리가 골라진 채로 보인다. 목록에서 빼는 것은 "건너뛰기"가 맡는다. 미분류 개수는 [AI로 한 번에 정리] 버튼이 알려 준다.
- [구현] 줄: 썸네일 + 제목(14px) + 주소·설명(12px) + [카테고리 선택][저장][건너뛰기]. 그림자 카드, 반경 20px.
- [구현] 주소 아래 태그 칩 줄(2026-11-22): 내 링크와 같은 모양. 홈은 카테고리 고르기가 따로 있어 태그만 보여 준다. 태그가 없으면 그리지 않는다.
- [구현] 카테고리 고르기와 적용(FEAT-008, 2026-11-22). 1차는 드롭다운(`select`) + 맨 아래 "새 카테고리"로 만들었다. 같은 이름이면 이미 있는 카테고리를 쓴다. 1~20자를 벗어나면 오류 테두리와 문구. 카테고리가 0개면 [저장]은 누를 수 없다(먼저 만들어야 한다).
- [구현] 고르기 부품(FEAT-008 AC-13, 2026-11-22): 검색칸 + 목록을 한 부품으로. 열면 전체가 보이고 안 쳐도 고를 수 있다. 글자를 넣으면 공백·대소문자를 무시하고 좁혀진다("모션" → "모션 그래픽"). 맨 아래에만 `새 카테고리 "..." 만들기`(똑같은 이름이면 만들지 않고 그것을 고른다). ↑↓·Enter·Esc, 바깥 누름으로 닫기. 모바일은 아래에 붙는 시트. 고르기 전에는 "카테고리 선택"이고 [저장]을 막는다.
- [구현] 목록 순서(AC-14)와 고정(AC-15, 2026-11-22 서버 구현): 고정 먼저 → 한글 → 영문 → 숫자 → 그 밖 → 이름순. 핀으로 최대 8개 고정. 고르기 목록의 "고정" 묶음 표시는 고르기 부품과 함께 붙인다.

### 버킷 (FEAT-009 · BKT 예정)

- [구현] 카드 틀 없이 썸네일(16:10) 하나, 왼쪽 위 책갈피, 이름은 썸네일 안 왼쪽 아래 흰 글자(14px, 아래 62% 검정 그라데이션), 설명 한 줄은 썸네일 아래(값 있을 때만). PC 3열, 모바일 가로 스크롤 220px. 마우스 올리면 2px 떠오름(0.15초).
- [구현] 준비 중: 서버 없어 실제 홈에는 안 보임. 미리보기·예시에서만.
- [예정] 버킷 목록·상세(BKT) 생기면 카드가 버킷 상세로 가는 링크가 된다.

### 공유용 링크 (FEAT-009, 이전 이름 "공유한 페이지")

- [구현] 테두리 상자 안 행 + 구분선, 회색 아이콘 타일, 공개/비공개 알약, 링크 복사. 서버 없어 미리보기·예시에서만.

### AI로 한 번에 정리 (LINK-04)

- [예정] 최근 추가한 링크 섹션 머리에 [AI로 한 번에 정리] 버튼. 미분류 2개 이상일 때만. 자세한 규칙은 [LINK-04](LINK-04-ai-organize.md).
