- [예정] MCP 연결 · 휴지통 · 설정 · 화면 모드 · 로그아웃은 **계정 메뉴**로 옮긴다(헤더에 메뉴를 더 늘리지 않는다).
- [예정] 모바일은 하단 탭 4개(홈·링크·버킷·공유) + 머리(로고·검색·계정). PC 상단 탭과 같은 목록이다. 자세한 차이는 아래 "모바일만 다른 것".
- [차이] 지금 코드는 PC 사이드바(접기 상태 저장) + 위쪽 막대다. v3로 가면 `AppShell`의 사이드바와 접기 기능이 사라진다.

## 요소별 규칙

### 1. 링크 저장 (FEAT-001)

**저장 경로에는 결정이 0개, 바로 뒤에 선택 1개, 나머지는 원할 때 모달.** 이것이 이 화면의 핵심 규칙이다.

- [예정] 본문 맨 위 큰 한 줄(높이 60px, 밑줄 입력) + [저장]. 검색은 헤더에 있으므로 이 칸은 **저장 전용**이다.
- [예정] 붙여넣고 [저장]이면 **바로 저장**한다. 모달을 띄우지 않는다. 카테고리가 없으면 미분류로 들어간다.
- [예정] 저장하면 칸 아래에 **방금 저장한 줄**이 하나 생긴다: 썸네일 · 제목 · 주소 · "저장했어요" · [카테고리 고르기] · [자세히].
  - **카테고리**는 여기서 끝난다. 검색 + 목록이 한 몸인 고르기 부품(FEAT-008 AC-13)이 열린다.
  - 무시하고 다음 링크를 붙여넣어도 된다. 그 링크는 미분류로 남아 아래 미분류 섹션과 AI 정리가 맡는다.
  - **[자세히]** 는 링크 수정 모달(LINK-03)을 연다. **제목 · 태그 · 이미지 · 카테고리**를 모두 거기서 고친다.
- [예정] 같은 모달을 내 링크·버킷의 ⋯ 메뉴에서도 쓴다. 입구만 여러 개고 화면은 하나다.
- [예정] 이미지(선택, 2026-11-22): 안 고르면 링크에서 가져온 그림을 쓴다. 직접 고르면 그 그림이 썸네일이 된다.
- [구현] 지금은 "추가 정보 입력하기(선택)"를 펼쳐 제목·태그를 저장 **전에** 받는다.
- [차이] v3는 저장 전에 아무것도 묻지 않는다. 펼침 영역은 없어지고 [자세히] 모달이 그 일을 받는다.

### 모바일만 다른 것 (2026-11-22)

PC와 뼈대는 같지만 세 가지를 다르게 한다.

- **저장은 플로팅 + 시트.** 본문에 저장 칸을 두지 않는다. 오른쪽 아래 [+ 링크 추가](하단 탭 위 16px)를 눌러 아래에서 올라오는 시트를 연다. 시트 안에서는 카테고리를 묻지 않는다 — 저장하면 시트가 닫히고 홈 맨 위에 "방금 저장한 줄"이 펼쳐진다. 결정이 저장 뒤 하나뿐인 건 PC와 같다.
- **플로팅을 홈에서도 띄운다.** 저장 칸이 없어 유일한 입구이기 때문이다. PC 홈에서만 숨긴다.
- **카테고리는 2열 그리드 4개 + [더 보기].** 가로 스크롤을 쓰지 않는다. 가로로 미는 줄이 연달아 두 번(카테고리·버킷) 나오면 리듬이 끊긴다. 작은 화면에서는 썸네일 더미가 190px로 작아져 값이 떨어지므로 **이름 + 개수**만 둔다(고정은 초록 핀). 가로 스크롤은 **버킷 하나만** — 표지가 커야 의미가 있다.
- **공유한 페이지 섹션을 홈에서 뺀다.** 세 번째 스크롤까지 내려가는 섹션은 거의 열리지 않는다. 하단 탭 [공유]가 입구이고, 홈에서는 버킷 카드의 "공개 중" 표시로 흐름을 잇는다.
- 머리에는 로고·검색·계정만, 메뉴는 하단 탭 4개(홈·링크·버킷·공유). 고른 탭은 위쪽 초록 막대 3px(PC 밑줄과 같은 규칙).
- 미분류 정리 카드는 세로로 쌓아 버튼이 손가락 크기로 들어가게 한다.

### 2. 미분류 링크 (FEAT-009 · FEAT-008)

- [예정] 제목 옆에 개수, 줄 끝에 [모두 정리하기 →].
- [예정] 맨 위에 **정리 카드 1장**(그림자, 반경 20px): 썸네일 96×62 · 제목 15px · 주소·시각 12px · [카테고리 고르기] · [건너뛰기]. 손을 움직이게 하는 것은 이 카드다.
- [예정] 카드는 **한 번에 한 장**이다. 남은 것들을 썸네일로 늘어놓지 않는다(2026-11-22). 몇 개 남았는지는 섹션 제목 옆 개수가 알려 준다.
- [예정] **미분류가 0개면 같은 자리에 "최근 저장한 링크"가 들어간다**(2026-11-22 채택). 섹션을 비우지 않는다.
  - 보여 주는 방식은 미분류와 같다 — **한 번에 한 개**. 제목 줄 오른쪽에 `1 / 12`와 ‹ › 로 넘긴다.
  - 성격은 생김새로 구분한다: 할 일이면 **그림자 카드 + [카테고리 고르기]**, 다 끝냈으면 **그림자도 버튼도 없는 줄**이다. 똑같이 보이면 할 일이 끝없는 것처럼 느껴진다.
  - 맨 위에 초록 띠로 "모두 정리했어요"를 **하루만** 띄운다.
  - 줄에는 썸네일 · 제목 · 주소 · 카테고리 칩이 보이고, 누르면 링크 수정 모달이 열린다.
- [구현] 지금은 "최근 추가한 링크" 한 장씩이고, 미분류를 앞에 세우되 분류된 링크도 뒤에 나온다(D-19).
- [차이] v3는 **미분류만** 담는다. 분류된 링크를 다시 보는 자리는 내 링크다.

### 3. 카테고리 (FEAT-008)

- [예정] **가로 스크롤 한 줄**(2026-11-22 채택). 카드 폭 240px, 한 줄에 5개쯤 보이고 나머지는 옆으로 민다. 카테고리가 20개가 돼도 섹션 높이는 그대로다.
- [예정] 카드 안은 **겹쳐 쌓은 썸네일 더미**(최근 링크 3장, 34px씩 어긋나게) + 고정 핀(초록) + 이름 + 개수. 제목을 줄지어 쓰지 않는다 — 6개면 글이 18줄이 돼 훑어보기가 안 된다.
- [예정] 더미가 얇으면 링크가 적다는 뜻이라, 개수가 눈으로도 읽힌다. 썸네일이 없는 링크는 버킷 아트워크로 채운다.
- [예정] 버킷과 구분: 버킷은 **표지 한 장**(공유 페이지의 커버가 된다), 카테고리는 **여러 장이 쌓인 더미**(표지가 없는 서랍). 링크가 카테고리 하나 · 버킷 여럿에 속하는 것과 같은 방향이다.
- [예정] 오른쪽 끝에 흐림 한 겹 + 마우스를 올리면 화살표. 스크롤 위치는 화면을 떠났다 와도 기억한다.
- [예정] 순서는 서버가 정한다: 고정 먼저 → 한글 → 영문 → 숫자 → 그 밖 → 이름순.
- [예정] 줄 끝에 [관리](CAT-01 모달)와 [전체 링크 N](내 링크로).
- [예정] 전부 보는 곳은 내 링크의 칩 줄이다.
- [예정] 카테고리가 0개면 섹션 자리에 한 줄 안내 + [첫 카테고리 만들기].

## 모션

움직임은 **무슨 일이 일어났는지 알려 줄 때만** 쓴다. 꾸미려고 쓰지 않는다. 기본 길이는 0.15~0.2초, 가속은 `ease-out`(빨리 시작해 부드럽게 멈춤)이다.

| 어디서                  | 무엇이                                          | 왜                                                       |
| ----------------------- | ----------------------------------------------- | -------------------------------------------------------- |
| 저장 직후               | "방금 저장한 줄"이 **위에서 아래로 펼쳐진다**(높이 0 → 자동, 0.2초) | 링크가 어디로 갔는지 눈으로 따라가게 한다                |
| 저장 직후               | "저장했어요" 초록 글자가 **0.15초 동안 서서히 나타났다가** 4초 뒤 사라진다 | 성공을 알리되 다음 입력을 막지 않는다                    |
| 카테고리를 고르면       | 그 줄이 **왼쪽으로 살짝 밀리며 사라진다**(0.2초) | 정리가 끝났음을 몸으로 알린다. 미분류 개수도 같이 줄어든다 |
| 건너뛰기                | 카드가 **위로 8px 올라가며 사라지고** 다음 카드가 그 자리에 나타난다 | "넘겼다"와 "지웠다"를 구분해 준다                        |
| 카테고리 고르기 열기    | 패널이 **4px 아래에서 올라오며 나타난다**(0.15초) | 어느 버튼에서 나왔는지 이어 보이게 한다                  |
| 버킷 카드에 마우스      | **2px 떠오른다**(0.15초)                        | 누를 수 있는 것임을 알린다                               |
| 메뉴를 바꾸면           | 초록 밑줄이 **옆으로 미끄러진다**(0.2초)         | 어디에서 어디로 왔는지 보여 준다                         |
| 모바일 시트             | 아래에서 **올라온다**(0.25초), 내릴 때는 같은 길이로 내려간다 | 손가락이 끄는 방향과 같다                                |
| 모달(LINK-03)           | 배경이 어두워지며 모달이 **2% 커지면서 나타난다**(0.15초) | 화면 위에 한 겹 올라왔음을 알린다                        |

- 길이가 0.3초를 넘기지 않는다. 넘으면 느리다고 느낀다.
- 목록 전체를 다시 그리는 움직임(카드가 줄줄이 날아오는 것)은 쓰지 않는다. 한 번은 재밌고 두 번째부터는 방해다.
- `prefers-reduced-motion: reduce`이면 **모든 움직임을 끈다**. 나타나고 사라지는 것은 그대로 두되 즉시 바뀐다.
- 색만으로 알리지 않는다. 움직임도 마찬가지다 — 글자(“저장했어요”)와 개수 변화가 늘 함께 간다.
