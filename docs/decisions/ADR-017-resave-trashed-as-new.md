# ADR-017: 휴지통에 있는 링크를 다시 저장하면 새로 저장한다 (D-01 변경)

- Status: accepted (2026-11-19)
- Context / problem:
  - D-01(2026-10-28)은 삭제한 링크를 다시 저장하면 저장하지 않고 `409 BOOKMARK_DELETED` + 복구 안내를 줬다.
  - 사용 중 확인(2026-11-19): 다시 넣는 사람은 "새로 넣는 것"을 기대하고, 안내 문구와 복구 버튼이 한 단계를 더 만든다.
- Options:
  - (a) 휴지통 없이 바로 영구 삭제: 실수로 지운 링크를 되살릴 수 없고 휴지통·복구를 걷어내야 한다.
  - (b) 휴지통 유지, 휴지통에 있는 링크를 다시 저장하면 예전 행을 영구 삭제하고 새로 저장
  - (c) 휴지통 유지, 다시 저장하면 자동 복구(예전 제목·태그·썸네일 유지)
- Decision:
  - (b). 삭제는 지금처럼 휴지통으로 가고 복구할 수 있다. 휴지통에만 있는 URL을 저장하면 그 행(태그 연결 포함)과 썸네일 파일을 지우고 새 북마크로 만든다(201). 활성 북마크가 있으면 지금처럼 재사용한다(FEAT-001 AC-02).
- Consequences:
  - 다시 저장한 시점에 휴지통의 예전 링크는 복구할 수 없게 된다(의도된 동작).
  - 저장 API는 더 이상 `BOOKMARK_DELETED`를 주지 않는다. OpenAPI의 저장 409 문서와 web의 복구 안내 코드는 다음 api-client 재생성 때 정리한다.
  - 되돌리기: 서비스의 분기만 바꾸면 되지만, 이미 영구 삭제된 행은 되돌릴 수 없다.
