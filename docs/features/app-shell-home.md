# FEAT-009 — 앱 틀(사이드바·하단 탭)과 홈 화면 디자인

- Updated: 2026-11-19 (시안 동기화: 위쪽 막대·계정 메뉴·정리할 링크 카드·썸네일 대체 아트)
- Related: 07-BRAND 6·7장 / 화면 LINK-01·LINK-02 / [홈 와이어프레임](https://claude.ai/artifact/TVK97VZWLdiXH6GdM6PiBx)(E1·E3, P0) / FEAT-002 / FEAT-008(카테고리, 별도 브랜치)

## 목적 및 비범위

- 사용자 문제: 로그인 뒤 화면이 최소 UI(저장 + 목록 탭)라 서비스의 구조(정리 → 버킷 → 공유)가 보이지 않는다.
- 이번 작업에서 하지 않는 것: 서버 API 변경, 검색, 카테고리 칩 동작(FEAT-008), 버킷·공유 페이지·설정 기능, 링크 목록 화면 디자인 정리, 다중 선택.

## 검토한 대안

| 선택지                                                            | 장점                                   | 단점                               |
| ----------------------------------------------------------------- | -------------------------------------- | ---------------------------------- |
| A. 서버 없는 섹션도 샘플 데이터로 실제 홈에 표시                  | 디자인이 바로 다 보인다                | 가짜 데이터가 사용자 화면에 나간다 |
| B. 실제 홈은 데이터 있는 섹션만, 디자인 확인은 개발 전용 미리보기 | 사용자 화면은 정직, 디자인도 확인 가능 | 미리보기 경로 관리 필요            |

- 추천 및 근거: B(사용자 결정 2026-11-16). 비어 있는 섹션은 숨긴다는 홈 규칙과 맞다.
